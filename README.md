# Nasa-Learning-Hub
Educational website that will help people learn about NASA and space exploration.
Project Idea: 
This website was designed to allow people to learn more about NASA and space itself. In this website we will include a little quiz to keep your mind sharp and fun facts. This allows NASA to make learning about space less complicated and more engaging.
Technologies/Tools used:
GitHub: Managing and organizing the project
HTML: Website creation
JavaScript: Allows quiz to work
CSS: Website design
How to run the project:
1- Download project from GitHub
2- Open project folder
3- Open index.html file in your web browser
4- Read the fun space facts and try out the quiz
